# 🖥️ Info-Apps-bbQ24

Willkommen im zentralen Repository für didaktische Informatik-Apps. Diese Anwendungen wurden im Rahmen der **Informatik-Weiterbildung (bbQ24)** an der TU Dresden entwickelt.

Ziel ist es, fachwissenschaftliche Inhalte für den Unterricht (Sek I / Sek II) didaktisch reduziert und interaktiv zugänglich zu machen.

### ℹ️ Hinweise zur Nutzung

1.  **Windows (.zip):** Nach dem Download Rechtsklick -> *"Alle extrahieren"*. Starten Sie dann die `.exe`. (Bei Warnmeldung: "Weitere Infos" -> "Trotzdem ausführen").
2.  **Android (.apk):** Auf das Handy laden. Ggf. muss die Installation aus "unbekannten Quellen" erlaubt werden.
3.  **Quellcode:** Jeder Ordner enthält ein eigenständiges Flutter-Projekt.
